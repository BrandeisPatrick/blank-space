## 🚀 Quick Start

```bash
# 1) Clone
git clone https://github.com/BrandeisPatrick/blank-space
cd blank-space

# 2) Configure (optional: copy and fill in env values if needed)
cp .env.example .env

# 3) Install & run
npm install
npm run dev
# open http://localhost:5173  (or the port shown in your terminal)
